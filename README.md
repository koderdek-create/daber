# Дабер — разговорный иврит с ИИ

Устанавливаемое веб-приложение (PWA): болталка на иврите с ИИ-собеседницей Ноа.
Исправляет ошибки, показывает никуд, транскрипцию и перевод, умеет подсказки, озвучку и диктовку на иврите.

ИИ на выбор: Claude, ChatGPT, Grok или любая модель через OpenRouter — по вашему ключу API, который хранится только на устройстве. Запросы идут напрямую к выбранному сервису.

## Установка на Android
1. Откройте адрес приложения в Chrome.
2. Нажмите «Установить» в приложении или ⋮ → «Установить приложение».
